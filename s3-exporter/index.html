Project Overview

S3 Event Exporter is a high-performance, enterprise-grade Kubernetes application designed to process Amazon S3 events from SQS queues and export comprehensive Prometheus metrics. Built with Go for optimal performance, it features production-ready deployment configurations with Helm charts and comprehensive monitoring capabilities.

The Problem: AWS CloudWatch S3 Monitoring Limitations

❌ Best-Effort Delivery

AWS explicitly states CloudWatch metrics are "best-effort" - data points may be delayed, incomplete, or missing entirely.

❌ No Real-Time Events

CloudWatch only provides aggregated metrics, not individual S3 event details like user identity, source IP, or object-level metadata.

❌ Limited Security Insights

No user-level tracking, IP analysis, or anomaly detection for suspicious deletion patterns or bulk operations.

❌ No Custom Analysis

Cannot track hierarchical paths, file extensions, or custom business logic for data organization patterns.

Our Solution: Event-Driven Real-Time Monitoring

✅ 100% Event Capture

Every S3 event is processed via SQS with guaranteed delivery, retry logic, and dead letter queue handling.

✅ Real-Time Processing

Individual event analysis with user identity, source IP, object metadata, and latency tracking in real-time.

✅ Advanced Security

Built-in anomaly detection for system deletions, bulk operations, and unauthorized access patterns.

✅ Custom Intelligence

Hierarchical path analysis, file type distribution, and configurable business logic for data organization insights.

Key Features

  • Real-time S3 event processing from SQS queues with configurable batch sizes
  • 12+ comprehensive Prometheus metrics with anomaly detection capabilities
  • Production-grade Helm charts with customizable values and resource management
  • Docker-based deployment with multi-architecture support
  • Enterprise-ready monitoring, alerting, and observability features
  • Configurable metrics enabling/disabling for optimized performance

  • Built-in anomaly detection for security monitoring

Installation Methods

Choose from multiple installation methods based on your infrastructure setup and requirements.

Helm Installation (Recommended)

Production-ready deployment with configurable values and resource management.

# Add the Helm repo helm repo add helm-charts \ https://code-by-rupinder.github.io/helm-charts/ helm repo update # Install with default values helm install s3-event-exporter \ helm-charts/s3-event-exporter # Install with custom values helm install s3-event-exporter \ helm-charts/s3-event-exporter \ --set config.sqs.queueUrl="https://sqs.region.amazonaws.com/account/queue" \ --set config.metrics.enabled=true

Docker Installation

Containerized deployment with volume mounting for configuration.

# Pull the latest image docker pull codebyrupinder/s3-event-exporter:latest # Run with configuration file docker run -d \ -v $(pwd)/config.yaml:/app/config.yaml \ -p 8080:8080 \ codebyrupinder/s3-event-exporter:latest # Run with environment variables docker run -d \ -e SQS_QUEUE_URL="https://sqs.region.amazonaws.com/account/queue" \ -e METRICS_ENABLED="true" \ -p 8080:8080 \ codebyrupinder/s3-event-exporter:latest

Prometheus Metrics

Comprehensive metrics suite providing deep insights into S3 event patterns, performance, and anomalies. Each metric is designed for specific monitoring and alerting scenarios.

s3_event_total

Tracks all S3 events by type, bucket, and subtype. Enables monitoring of event patterns and helps identify unusual activity spikes or drops in S3 operations.

s3_event_object_size_bytes

Histogram of object sizes with configurable buckets (1KB to 16TB). Useful for storage optimization, cost analysis, and identifying large file uploads that might indicate data dumps or backups.

s3_event_ip_total

Source IP tracking for security monitoring and geographic analysis. Helps detect unauthorized access attempts and unusual access patterns from unexpected locations.

s3_event_prefix_total

Object prefix distribution for storage pattern analysis. Enables understanding of how data is organized and accessed across different application components.

s3_events_hierarchical_path_total

Hierarchical path tracking at configurable directory depth. Provides insights into folder structure usage and helps optimize data organization strategies.

s3_bucket_extension_files_total

File type distribution by extension tracking both creation and deletion. Useful for understanding data types being stored and compliance monitoring.

s3_event_latency_seconds

Processing latency between event creation and processing. Critical for performance monitoring and ensuring real-time processing requirements are met.

s3_event_anomaly_total

Anomaly detection covering system deletes, delete markers, and bulk operations. Essential for security monitoring and detecting potentially malicious activities.

s3_lifecycle_expiration_total

Lifecycle policy deletion tracking by bucket and prefix. Helps monitor automated cleanup processes and optimize lifecycle policies for cost management.

s3_delete_total

Comprehensive delete tracking with type and reason classification. Provides detailed insights into deletion patterns and reasons, crucial for data retention compliance.

s3_event_parser_errors_total

Event parsing error monitoring for reliability tracking. Ensures data quality and helps identify issues with event format changes or processing problems.

Configuration Options

Flexible configuration system supporting YAML files, environment variables, and Helm values. All aspects of the application can be tuned for your specific requirements.

Metrics Control

Enable or disable individual metrics for optimized performance and reduced resource usage. Each metric type can be controlled independently.

SQS Integration

Configurable queue URLs, batch sizes (1-10), polling intervals, and visibility timeouts. Supports multiple queues and dead letter queue handling.

Histogram Buckets

Customizable size buckets for object size distribution analysis. Default exponential buckets from 1KB to 16TB with configurable ranges.

Path Depth Tracking

Configurable hierarchical path tracking depth (1-10) for analyzing folder structure usage patterns and optimizing data organization.

Resource Management

CPU and memory limits with Horizontal Pod Autoscaler (HPA) support. Configurable replica counts and resource requests/limits.

Security & Compliance

RBAC configuration, security contexts, pod security policies, and network policies for enterprise security requirements.
